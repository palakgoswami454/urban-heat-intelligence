How it works

  1. Satellites — Landsat 8/9 surface temperature + Sentinel-2 imagery + elevation, every pre-monsoon summer since 2019.
  2. Deep learning — a U-Net learns how land cover and terrain shape surface heat, and fills cloud gaps.
  3. Explainability — occlusion and permutation analysis show why each area is hot.
  4. What-if — the model simulates greening and cool roofs to estimate cooling per area.
  5. Forecast — an attention-LSTM predicts daily max temperature 7 days ahead.
